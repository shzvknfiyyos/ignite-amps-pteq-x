## Overview

PTEq-X models the iconic Pultec EQP-1A passive equalizer circuit, reproducing the simultaneous boost and cut bass shelving behavior and the HF presence peak that define the Pultec sound.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ignite Amps PTEq-X** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pultec Model** | Passive LC filter network emulation matching EQP-1A circuit topology |
| **Bass Shelf** | Simultaneous low-frequency boost and cut interaction matching hardware |
| **HF Presence** | High-frequency bell peak with the distinctive Pultec air character |
| **Transformer** | Output transformer harmonic saturation adding density and weight |
